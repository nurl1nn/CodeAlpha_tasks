## Projects

### 1. Hangman Game
A classic word-guessing game built in Python.
- Random word selection from a predefined list
- Letter-by-letter guessing with limited attempts
- Visual progress tracking

**Concepts used:** `random`, loops, lists, string manipulation

---

### 2. Rule-Based Chatbot
A simple rule-based chatbot that responds to predefined user inputs.
- Recognizes greetings, farewells, and common questions
- Random response selection for variety
- Case-insensitive input handling

**Concepts used:** `random`, loops, conditionals, input/output

---

### 3. Stock Portfolio Tracker
A stock portfolio tracker that calculates investment values and saves results.
- Predefined stock prices dictionary
- User can add multiple stocks and shares
- Portfolio saved to a `.txt` file

**Concepts used:** dictionaries, file handling, loops, f-strings
